# dotfiles

Personal configuration files for Debian-based systems.

This repo uses a **copy-based deployment model** — files here are the source of truth and get copied into `$HOME` and `$HOME/.config` via the install script. Nothing is symlinked.

## Structure

```
dotfiles/
├── home/          → copied to $HOME (.bashrc, .profile, .gitconfig)
├── config/        → copied to $HOME/.config (starship.toml, etc.)
└── install.sh
```

## Usage

```bash
# Dry run first (recommended)
DRY_RUN=1 ./install.sh

# Actual install
./install.sh
```

Existing files are backed up to `~/.dotfiles-backup/<timestamp>/` before being replaced. The backup mirrors the repo structure, so restoring is straightforward:

```bash
cp ~/.dotfiles-backup/20250115-143022/home/.bashrc ~/.bashrc
```

## What belongs here

Ask: *If I reinstalled tomorrow, would I want this file back exactly as-is?*

**Yes:** shell config, git config, prompt config, tool settings I've deliberately edited.

**No:** application state, caches, autogenerated files, secrets, browser profiles, desktop session data.

Keep it small, auditable, and stable.

## What this repo doesn't do

- Install packages
- Manage secrets
- Configure system-level settings
- Theme the desktop

Those are separate concerns.
