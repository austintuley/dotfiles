# Dotfiles Scope

## Decision
Track only human-authored configuration in this repository.

## Included
- Shell configuration (`.bashrc`, `.profile`)
- Git configuration (`.gitconfig`)
- Prompt configuration (`starship.toml`)
- Tool configs that are intentionally edited

## Excluded
- Application state
- Electron configs
- Browser profiles
- Desktop or session data
- Caches and autogenerated files
- Secrets and keys

## Rationale
- Application state is noisy and unstable
- Reproducing behavior matters more than reproducing state
- Keeping scope small keeps the repo trustworthy

## Rule
If I did not edit it intentionally, it does not belong here.
